先把角色认清 Meet the cast

故事不是另一套知识。它只是把抽象技术换成你已经熟悉的餐馆场景。The story is not extra material. It translates abstract technology into a familiar restaurant.

你 / 老板 → 学习者
你要学的是设计、连接和管理整个 AI 系统。You learn to design, connect, and run the whole AI system.
学霸店员 → AI 模型
知识很多，会说话，但需要清楚指令，也可能答错。Knowledgeable and fluent, but needs clear instructions and can be wrong.
店长 → Agent
模型有了工具和循环，能自己决定下一步做什么。A model with tools and a loop that can choose its next step.
客人 → 产品用户
他们不关心厨房多复杂，只关心问题有没有被解决。They care less about the kitchen than whether their problem gets solved.
AI 小馆 → AI 应用
代码、模型、资料、工具和规则合在一起，才是一家能营业的店。Code, model, knowledge, tools, and rules together make a working product.
菜谱库 → RAG 资料库
模型不会凭空记住你的资料；要先找证据，再按证据回答。The model retrieves your evidence first, then answers from it.

建立链接的方法：先讲故事，再翻译回技术。例如，“老板让店员翻菜谱回答客人”就是“开发者让模型检索资料后回答用户”。能从两边来回说，链接就建牢了。Build the link: tell the scene, then translate it back into technology. “The owner asks the server to consult the cookbook for a guest” becomes “the developer makes the model retrieve evidence before answering a user.” If you can move both ways, the connection is solid.

比喻对照表 Metaphor map

先问“像在哪”，再念一次女巫的升级咒。每道魔咒都把初级比喻推深一层：不是惩罚，而是揭开技术真正多出来的那部分。能说出升级前后，再把故事翻译回技术，链接才真正建立。First ask where the metaphor fits, then cast the witch's upgrade spell. Each spell moves the beginner's picture one level deeper. It is not a punishment; it reveals what the real technology adds. Explain the before and after, then translate the story back into technology.

走地图的六条规矩 Six rules for using the atlas

01

它是依赖图，不是死课表。

卡住就顺着路线往回找前置知识，不用硬顶。It is a dependency map, not a rigid calendar. Trace backward when stuck.

02

默认从零开始。

SQL、Pandas、终端都不假设会。每个新词先问“它替我解决什么问题？”Assume zero prior knowledge. First ask what problem each term solves.

03

每月留下一件能跑的东西。

M1 小接口 → M3 有出处的问答 → M5 上线产品。作品链比证书更值钱。Leave one working artifact each month. A chain of proof beats a certificate.

04

Prompt 要当代码管理。

记版本、留测试题、能回滚。别靠“这版感觉好像更聪明”。Version prompts, keep test cases, and make rollback possible.

05

先做工作流，再决定要不要 Agent。

固定三步能做完，就别请一个会自由发挥的店长。Build the workflow first. Use an agent only when judgment is truly needed.

06

M5 之后再选方向。

先把完整链条走一遍，再凭真实手感选产品、微调或自动化。Choose your specialty after Month 5, based on real experience.

地图用来认路，不用来赶路。A map is for finding your way, not for rushing.
